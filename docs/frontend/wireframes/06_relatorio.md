# Wireframe 06 — Relatório

## Objetivo
Transformar a análise em artefato profissional.

## Estrutura

```text
RELATÓRIO DE COMPARAÇÃO

Documento A × Documento B

RESUMO EXECUTIVO
[resumo]

ALTERAÇÕES RELEVANTES
[lista]

DIFERENÇAS
[cards/tabela]

COBERTURAS
[resumo]

EXCLUSÕES
[resumo]

EVIDÊNCIAS
[lista auditável]

METODOLOGIA
[descrição]

[ Exportar PDF ]
```

## Princípios
- aparência de documento corporativo;
- hierarquia editorial;
- evidências preservadas;
- score apenas auxiliar.

## Componentes
ReportHeader, ExecutiveSummary, DifferenceList, EvidenceList, ExportButton.
